# Laith Ellabadi · portfolio

Live at **https://bylaith.com/**

A single-page portfolio about agentic coding, AI and robotics. It's plain HTML, CSS and JavaScript with no build step. three.js comes from cdnjs and the fonts come from Google Fonts.

- `index.html` is the whole site.
- `films/` holds the ten project films (1080p, rendered in Remotion from real screen recordings) and their posters.
- `media/` holds the photos (IEEE RAS JUST chapter photos, courtesy of the chapter).
- `og.jpg` is the link preview image.

GitHub Pages serves the site from `main`, so anything pushed to `main` goes live.

Try it: hold **X** for the x-ray lens, press **⌘K** to ask the page, and merge all ten pull requests.
